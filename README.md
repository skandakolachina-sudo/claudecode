# claudecode

## First Shares

[`first-shares/`](first-shares/) is a stock market course for high schoolers that runs as a website on your own computer. It has 14 lessons with quizzes, a ten-year decision game, a math gym, a final exam, a glossary and a plan builder.

To use it, download the folder (on GitHub: **Code → Download ZIP**), unzip it, and double-click `first-shares/index.html`. See [`first-shares/README.md`](first-shares/README.md) for details.
